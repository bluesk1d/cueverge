# Multi-output demo

This synthetic package demonstrates scene schema version 2 with:

- two media-agent resources
- one explicit clock-source media output
- two independently routed pixel outputs
- resource-specific baseline and safe-state lighting looks
- a looping show program

Media assets are intentionally omitted, so this package is intended for the
in-memory simulation and schema validation rather than a physical mpv agent.
Installation-specific addresses, geometry, and copyrighted media do not belong
in this example.
